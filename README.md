# DE KOMMER! HÆLP OS! (Esoteric Language)
This is a joke programming language (or esoteric language) that's inspired by Guts and Blackpowder callout. The interpreter was written in python.

NOTE: It has some of the issues in interpreter so it's an experimental language

This esolang is inspired by Guts & Blackpowder Callout and it was made for a joke
This is probably be the first Guts & Blackpowder Esoteric Language or not
How to program, you have to use DE KOMMER! HÆLP OS! by counting on how many words, can be counted up 1 to 9 (DE to DE KOMMER! HÆLP OS! DE KOMMER! HÆLP OS! DE)
e.g. "DE" is 1, "DE KOMMER! HÆLP OS!" is 4, "DE KOMMER! HÆLP OS! DE KOMMER! HÆLP" is 7.
Line represent the digit so 3 line is 3 digit

Example:

1st line DE KOMMER! HÆLP OS! DE KOMMER! HÆLP OS! DE KOMMER! (0)
2nd line DE KOMMER! HÆLP OS! DE KOMMER! HÆLP (7)
3rd line DE (1)
4th line DE KOMMER! HÆLP OS! DE KOMMER! HÆLP OS! DE KOMMER! HÆLP OS! (Input as ASCII)

So the ASCII of 071 to string is "G"


DE KOMMER! HÆLP OS! DE KOMMER! HÆLP OS! DE KOMMER! is Zero not to be confuse
DE KOMMER! HÆLP OS! DE KOMMER! HÆLP OS! DE KOMMER! HÆLP OS! can inserted as ASCII decimal
The interpreter converts "DE KOMMER! HÆLP OS!" into a string from ASCII then converts to python source code
To program, you mush write lines of code for digits and create new ASCII Character in order to make program works
Recommended to run the interpreter twice if you made a new code
